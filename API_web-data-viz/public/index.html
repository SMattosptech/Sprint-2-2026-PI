Tecnologia que cuida do café.

O CoffeeCare é um projeto que utiliza sensores para monitorar a umidade do solo e apresentar essas informações em uma plataforma digital. A proposta é ajudar produtores a acompanhar suas lavouras e tomar decisões com mais informação.

SOBRE O PROJETO

Mais informação para cuidar de cada cultivo.

O CoffeeCare conecta o monitoramento da umidade do solo à visualização de dados em uma plataforma digital. A ideia é transformar leituras dos sensores em informações acessíveis para apoiar o acompanhamento da lavoura.

01

Nosso propósito

Facilitar o acompanhamento das condições de umidade do solo por meio de tecnologia simples e informação organizada.

02

Nosso foco

Desenvolver uma solução voltada inicialmente ao cultivo de café, considerando a importância do manejo adequado do solo.

03

Nossa abordagem

Unir sensores, banco de dados e visualização em uma plataforma para tornar o acompanhamento mais prático.

COMO FUNCIONA

Do solo para a informação.

O projeto foi pensado para organizar a leitura dos sensores e facilitar a consulta dos dados em um só lugar.

1

Monitoramento

Um sensor capacitivo realiza a leitura da umidade do solo.

2

Envio e organização

As leituras são encaminhadas para a estrutura digital do projeto e organizadas para consulta.

3

Visualização

A plataforma apresenta as informações para apoiar o acompanhamento da lavoura.

POR QUE COFFEECARE?

Tecnologia para apoiar melhores decisões.

Dados mais acessíveis

Consulte as informações de umidade de forma organizada em uma plataforma digital.

Acompanhamento prático

Reúna as leituras dos sensores para observar as condições do solo ao longo do tempo.

Apoio ao manejo

Use os dados como apoio à análise da lavoura, junto da experiência do produtor e de outras informações agronômicas.
